# TV Budget — Use Cases

| ID   | Actor  | Use Case |
|------|--------|---------|
| UC1  | Child  | As a child, I want to sign in with my YouTube account so I can see my subscribed channels. |
| UC2  | Child  | As a child, I want to browse subscribed channels so I can pick something without typing. |
| UC3  | Child  | As a child, I want to search by keyword so I can find specific content. |
| UC4  | Child  | As a child, I want to see recently watched videos so I can re-watch favourites quickly. |
| UC5  | Child  | As a child, I want full-screen video playback on the TV during my allowed screen time. |
| UC6  | Child  | As a child, I want a live budget countdown so I know when my session ends. |
| UC7  | Child  | As a child, I want a "5 minutes left" audio + visual warning so I can prepare to stop. |
| UC8  | Child  | As a child, I want "2 minutes left" and "30 seconds left" in-player banners so I know the video is about to end. |
| UC9  | Child  | As a child, I want the Back button to always return me to the home screen. |
| UC10 | Parent | As a parent, I want separate morning and afternoon time limits. |
| UC11 | Parent | As a parent, I want playback to stop automatically when the budget runs out. |
| UC12 | Parent | As a parent, I want to grant bonus minutes via a PIN-protected settings screen. |
| UC13 | Parent | As a parent, I want to pin channels so they appear first in the child's list. |
| UC14 | Parent | As a parent, I want keyword blocklist filters to exclude inappropriate content from search. |
| UC15 | Parent | As a parent, I want settings to sync from Google Drive so TV picks up changes made on my phone. |
| UC16 | Child  | As a child, I want a friendly "Time's Up" screen when my budget is exhausted. |
| UC17 | Child  | As a child, I want videos that don't fit my remaining budget to appear greyed out. |
| UC18 | Child  | As a child, I want full D-pad navigation so I never need a mouse or keyboard. |
| UC19 | Child  | As a child on Tizen TV, I want playback via the native YouTube app for best quality. |
| UC20 | Parent | As a parent, I want a 7-day watch history summary in Settings. |
